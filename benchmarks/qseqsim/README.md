# QSeqSim

This source contains 21 standalone OpenQASM 3 while-loop programs from the
QSeqSim evaluation: six RUS programs, three quantum-random-walk programs,
three Grover programs, and nine frozen random while-loop programs.

They are intentionally recorded with `paired = false`. They currently have no
second program and no `eq` or `neq` ground truth, so they are not counted as
Irene equivalence cases.
